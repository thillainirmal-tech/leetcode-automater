1,396 validated problem records

A dependency-free Node.js toolkit for Java, Python, C++, TypeScript, SQL, Pandas and Bash submissions. It checks account state, waits for the final judge result and records only accepted runs.

Get the latest release View source

Your LeetCode session token stays local and in memory. Never paste it into an issue, commit or screenshot.

Built for controlled runs

Useful automation without hiding what happens.

Validated dataset

Checks unique IDs, supported languages, source URLs and local solution files before a run begins.

Live account filtering

Skips already-solved problems and supports explicit retry and exclusion lists for focused sessions.

Final-result tracking

Waits for LeetCode's judge and records a submission as successful only after an Accepted result.

Multi-language sources

Includes Java, Python, C++, TypeScript, MySQL, Pandas and Bash records in one searchable catalogue.

Local token helper

The included Chrome extension creates the Merge Token locally from an authenticated browser session.

Open validation

The same project validator runs locally and in GitHub Actions, making dataset changes easy to review.

Three commands

Validate before you automate.

Review LeetCode's current terms and rate limits, then use a small target for your first run.

git clone https://github.com/thillainirmal-tech/leetcode-automater.git
cd leetcode-automater
npm run validate
npm start
